# DEMIURGE

A pixel-art god-simulation sandbox: shape a world, then watch ecosystems, civilizations and history emerge on their own.
Browser-only · React + TypeScript · Canvas 2D · all art and audio generated in code.

## Run

```bash
npm install
```

```bash
npm run dev
```

Open http://localhost:3000. `npm run build` type-checks and builds to `dist/`.

## Controls (so far)

Space pause · 1–5 speeds (1×, 2×, 5×, 10×, 25×) · F3 performance overlay · ` (Backquote) Dev Console · Esc close.
Hotkeys use physical key codes, so they work on any keyboard layout.
