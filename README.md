# DRtop

## The Life of Pablo — автопортрет, который невозможно закончить

**[The_Life_of_Pablo.pdf](The_Life_of_Pablo.pdf)** — 45 страниц, квадратный формат 250 × 250 мм (как буклет
к пластинке). Эссе об альбоме Канье Уэста *The Life of Pablo* (2016): литературная редакция статьи,
двадцать треков — двадцать разных «комнат» со своей палитрой, шрифтом и схемой, три Пабло
(апостол Павел, Пикассо, Эскобар) и один телефонный звонок.

Что внутри:

- обложка-оммаж (оранжевый #F28A55, повторяющееся название, Рембрандт в образе апостола Павла);
- содержание на «жёлтом блокноте» с зачёркнутыми названиями So Help Me God → SWISH → WAVES;
- хроника изменений альбома после выхода, кубистский «портрет из противоречий»,
  круги Эйлера «Три Пабло», схема обложки, карта голосов по титрам;
- по развороту на каждый трек: луч и хор (Ultralight Beam), «анатомия батоса» на Караваджо (Pt. 1),
  таблоидная «грамматика присвоения» (Famous), спираль обратной связи (Feedback), контактный лист
  (Highlights), кольцо из имени (I Love Kanye), гроссбух (FML), пропущенные звонки (Real Friends),
  волк в пяти состояниях (Wolves), телефонная полоса частот (Silver Surfer), дорожный знак (30 Hours),
  футболка «I feel like Pablo» (No More Parties in LA), чек (Facts), секвенсор (Fade),
  парящая сцена и «краудсорсинг самооценки» (Saint Pablo);
- «Архив времён» — годы всех сэмплов, сейсмограмма «владеть собой ↔ нуждаться в других»,
  карта мотивов, сноски и колофон. В PDF есть закладки по частям и трекам.

Схемы с пометкой «прочтение» — интерпретация текста, а не измерение; остальные построены на данных
(титры, длительности, даты релиза).

### Пересборка

Исходники — в `tlop/`: страницы на HTML/CSS/SVG (Python-генераторы `pages_*.py`), рендер в PDF —
Chromium через Playwright.

```bash
pip install pyphen pypdf
cd tlop && python3 build.py && python3 tools/finalize.py build/tlop_raw.pdf build/tlop.html ../The_Life_of_Pablo.pdf
```

Шрифты — Google Fonts (SIL OFL), изображения — общественное достояние (Рембрандт, Караваджо)
и The Met Open Access (CC0); все графики и иллюстрации нарисованы для этого издания.
